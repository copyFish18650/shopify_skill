# 字体、标题与整站视觉系统

基础站、精品站和自主设计都为本站确定协调的字体、字重、字号、行高、行宽、对齐和组件排版，执行 [跨站差异规范](site-diversity.md)。精品默认保留用户认可的成熟排版与组件关系，只按本次字串、图片和品类小幅适配，无需逐站重造字体与主要结构；基础与自主模式按其差异要求设计。不可用字体采用有许可且经比较的方案，不假定源站商业字体可打包。

用户要求每站精致、排版更有设计感。结合本店商品、图片和购物任务核对标题/正文家族、字重层级、行宽、留白和对齐。精品记录成熟排版保留项及小幅适配，基础与自主模式记录相对近期结果的实质区别；实际看字体加载后的桌面/手机，而非凭系统字体回退截图评审。

## 标题与字体

- 首页大标题针对本次商品和陈列写，自然美式英语、简短、有明确语义，避免每站套用同一句泛用口号或固定“eyebrow + 双行标题 + 描述”。字形、字宽、字重、光学字号、行距与图片关系共同形成特色。可使用醒目的窄体、几何体、衬线或适合产品的其他方向；不是固定十套组合循环。
- 主标题可以有个性，商品名、价格、筛选、表单、导航和政策要易读。少量字体家族通常足够；避免在同一页堆多种装饰字。标题强调应出于构成，不默认给一个词换色或斜体；断行针对真实句子与手机宽度，不将文字转成图片。
- 小字、划线价、辅助文字与 Footer 不以过浅颜色或低透明度表现层级，按 [实际色面对比度](color-and-surface.md#配色质感与文字清晰度) 验收。字号、字重、行高和间距共同建立主次；超细字、强字距和低对比不能组合成难读文本，桌面／手机及展开状态都要清楚。
- 采用允许分发的字体，保存相应许可。优先随主题打入合适的 WOFF2 子集，正确声明 family/weight/style 与 `font-display`，只预加载关键首屏字体；或使用原生 Shopify 字体设置。保留系统回退与多语言字形回退，验证真实字体、长标题、320px、文本放大和加载失败。
- 给店主合适的编辑器开关/排版设置，保留现有设置值与原生功能。字体应覆盖各页面，卡片、按钮和页脚不能遗留另一套不协调的系统默认样式。
- 复用规则与清楚的操作语义；精品优先保留成熟首页构成、商品密度和主要交互，基础与自主模式按本站方向设计。不要为追求标题设计编造品牌故事、认证、销量或 SKU。

## 色面与明暗系统

执行 [配色与色面构成](color-and-surface.md)。先决定整站的主地、商品与阅读面、强调区及其明暗关系，再选具体颜色；不以白色/浅灰主底作为自动起点。原生颜色方案、默认值、保存配置和实际组件 token 应一致，颜色设置必须能影响真实页面。深色与饱和色同样覆盖内页、菜单、表单、弹窗及交互状态，不能只装饰首页或 Footer。字体和层级随该底色实测，保留真实商品图片的原色。

## 必需设计技能与额外参考

先执行 [三技能准备](design-skill-prerequisites.md)。Taste、独立 Design 与 Garden 前端模块已内置在本技能的 `assets/design-skills/`，通过主技能统一读取和编排；完整性检查与规则读取是开始编写前的必需项，其余技能按需使用。分享主技能的完整目录即可携带三者，不要求复现原机器的外置安装或绝对路径。

- [Taste Skill](https://github.com/Leonxlnx/taste-skill)，内置入口名 `design-taste-frontend`：用于题材驱动的独立构图、字体与实图评审；读取当前版本，不能把其随机抽样的构图或营销页硬规则当作所有商城母版。用户要求的 4/2 商品网格、完整 Footer、轻量 CSS 与真实原生交易优先，不为检查数量加重动画。
- [Design Skill](https://github.com/gabros20/design-skill)，内置入口名 `design`：用于购物路径、导航、状态设计、视觉系统和实际成品评审。按它的任务路由完整读取本次选定参考；不能用设计原型代替原生 Shopify 主题或发布验证。工作产物放本次工作目录，不因其默认 ledger 约定自动提交 Git，也不放进最终两文件目录。
- [Garden Skills](https://github.com/ConardLi/garden-skills)，本技能内置其前端模块 `web-design-engineer`：用于设计判断、视觉层级与组件状态。已授权自主设计时直接落实决定，不重新要求逐项选方案；生产主题的调节项使用 Theme Editor，不将原型 Tweaks 面板放进顾客购物流程。
- [Anthropic Frontend Design](https://github.com/anthropics/skills/tree/main/skills/frontend-design)，安装名 `frontend-design`，额外参考：主体明确的视觉方向、非公式化构成和字体/文案判断；与上面的独立 Design Skill 分开，不互相冒充。
- [UI/UX Pro Max](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill)：可搜索字体搭配、色彩、布局与交互知识。搜索结果是建议；核对是否符合商品与原生 Liquid/CSS 实现，不为输出的框架/GSAP 片段安装无关库，不照抄固定段落顺序或虚假社会证明。
- [Web Design Guidelines](https://github.com/vercel-labs/agent-skills/tree/main/skills/web-design-guidelines)：审查语义、焦点、表单反馈、字体/图片加载、触控和响应式边界。针对本次文件运行，修复适用项；不把 React 等框架特定规则强加给 Liquid。

已安装不等于本次已经应用，更不等于已完成审美评审。记录所采纳的设计决定、实际改动和未采用建议的原因，按 storefront-depth 与 validation-and-delivery 实测。本技能已有的审美、轻量 CSS、原生功能、真实目录和政策边界持续优先。
