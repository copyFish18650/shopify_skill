# 自主选品的小商品站

用于用户让 agent 自行选日用品、小挂架、收纳、清洁或其他小商品的任务。用户明确指定全站抓取时仍按 source-catalog 完整采集；自主选品是有目的的策展目录，不伪称采集了整个来源站。

## 来源与各站区别

- 可用 TikTok Shop（TK）、商家/品牌公开目录及其他可核实来源；用户最新要求取消中国国内可采购限制，不验证或承诺国内供货，也不强制阿里巴巴/1688。后续用户明确恢复限制时再按当次要求核实。
- 每站先确定选品侧重和购物分类，再选择实际在售商品。批量站以真实款族互斥分配，同款各色／尺码及跨来源别名只能归一站；商品组合、分类重点和首页陈列也应有实质区别。执行 [catalog-uniqueness.md](catalog-uniqueness.md)，先核实独立款池能覆盖总量，再生成各站目录；不足就扩源并报告缺口，不复制目录、拆变体或凭空增加 SKU。
- 搜索/聚合/推荐页用于发现。正式收录要有具体商品及可售规格、实际价格/币种、图片和可回查 URL；不能靠搜索摘要、销量或“热门”标签推断库存。页面无法访问或信息不全时换可验证来源，记录未采用原因，不绕过登录或验证。
- 正常小商品优先；商品品牌、规格和图片保持一致，不把外观相似款当成同一 SKU，不删除品牌身份来冒充通用品。描述重写为准确的美式英语商品信息，不移植来源店履约、评价、优惠与认证。
- 原始快照、来源 URL、采集时间、选品与排除理由留在工作目录。可售状态是采集时快照，不是持续同步或实仓数量证明；不得捏造来源库存。新目录可采用下述已获准的商家虚拟配额，但仍只使用实际可售选项，不把售罄选项混入。

## CSV 与主题一起完成

CSV 使用当前 Shopify 官方字段、UTF-8、正确逗号/引号/换行与实际商品/规格/图片行关联。以当前官方样表核对字段，兼容旧表头不等于可随意造列。供应来源备注留在工作目录，不加不受支持的“TK 链接/采购价”等自定义列。详细原生依赖与验证见 source-catalog 和 csv-and-home-catalog。

从采购或异币种来源选品时，区分来源价格与本次店面售价，不把其他币种数字直接当 USD，不造划线价。价格、重量、库存跟踪设置有依据；按 [完整性规范](catalog-completeness.md) 为每件商品补标准类别／Type／主集合。新目录逐真实可售规格默认使用已获准的 60–99 件随机虚拟配额及 Shopify 跟踪，保存映射并在重跑时沿用，不冒充来源／实仓库存；当前要求实际库存同步时才补查或引导提供实际数量。不静默选择未跟踪，也不将缺少当前适用数量依据的 CSV 称为完整。

所有导出图片逐 URL 核对为公开可访问的真实图片；浏览器内可看并不证明 Shopify 能拉取。排除需登录、依赖 Cookie/防盗链或临时签名的链接；有必要且在本次授权内时放到稳定公开图片托管，否则改选可验证图片的商品。不能用本地路径或第三份必装图片包补救。

更新每站主题的计划分类、可选来源映射、首页文案、专题选品、图像与品类指南；实际 Header/首页仍读取导入后的原生集合/Type/商品。各站用自己的最终 CSV 预览，不能把同一测试目录用于全部站后声称已验证。

独立重新解析最终 CSV，核对列数、编码、handle 唯一商品、规格组合与 SKU、价格、图片顺序、分类归属和原生发布状态；与源快照逐项比对，并按适用表格技能往返检查。有实店导入授权和访问条件时验证导入；否则明确只完成本地格式/对象模拟。不得保证未经实际导入的新 CSV 必定无后台配置问题。

每站最终文件夹默认提供 **主题 ZIP + 商品 CSV + 实际首页截图**，截图按 [首页截图交付](validation-and-delivery.md#首页截图交付) 验收，供预览且不参与安装。重做已有目录先备份旧成品，全部验证后替换并同步受影响的截图。CSV 导入不会删除目录中省略的旧商品；已导过旧版的店铺需要单独处理旧商品/集合，不能在未授权时自动删除。改选品不要随意改同一真实商品的稳定 handle 造成重复。

官方依据（2026-10-29 核对，执行时检查更新）：[CSV 字段/依赖/图片](https://help.shopify.com/en/manual/products/import-export/using-csv)、[产品导入与覆盖规则](https://help.shopify.com/en/manual/products/import-export/import-products)。
